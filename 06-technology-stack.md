# Technology Stack

## Frontend
- Angular 20
- Standalone components
- DevExtreme 25.1
- Angular Signals for state
- Shared `@maccnet` libraries
- TypeScript models generated automatically

## Backend
- .NET 8 Web API
- Dapper
- SQL Server for CM and AM

## AI
- Python
- Flask
- LangChain
- PostgreSQL for AI / RAG
- Azure OpenAI
- Claude

## Platform & Delivery
- Monorepo described as four repositories unified
- Docker
- CI builds
- GitHub Actions deployments
- WorkOS SSO
- Swagger API documentation

## Design Intent
The technology choices support:
- Modern web delivery
- Maintainability
- Cloud deployment
- Continuous delivery
- AI-assisted operations

## Important
This document records the technology stack stated by the source. It does not prescribe package versions beyond those explicitly documented.
