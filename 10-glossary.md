# Glossary

| Term | Meaning in this project |
|---|---|
| MACC Gentue | The modernized web platform described by the source document |
| CM | Customer Management |
| AM | Account Management |
| Mimir | AI Assistant for chat, agents, charts, insights, reports and summaries |
| RAG | Retrieval-Augmented Generation used by the AI service |
| Agent | Mimir mode that can use tools for live-data lookups |
| WorkOS SSO | Authentication/identity service used by the platform |
| Dapper | .NET data-access technology used by the API |
| DevExtreme | UI component library used by the Angular frontend |
| API | .NET 8 REST API |
| AI Service | Python/Flask/LangChain service hosting Mimir functionality |
| CM DB | SQL Server database for Customer Management |
| AM DB | SQL Server database for Account Management |
| AI DB | PostgreSQL database used for AI/Mimir and RAG |
| QA | Environment used to validate the exact production build |
| Beta | Environment for early feature validation |
| Production slots | Azure deployment slots used for live company deployments |
| ChangeBy | User context mentioned for audit tracking |
| USP bundle | Bundle type mentioned under AM Catalog & Services; detailed meaning is not defined in the source |
| AR | Accounts Receivable, referenced under CM billing |
