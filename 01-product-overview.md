# Product Overview

## Vision
MACC Gentue replaces legacy desktop CM/AM software with a modern web application that combines customer operations, account/infrastructure management, analytics, reporting, and AI assistance.

## Core Modules

### Customer Management (CM)
CM covers:
- Customers
- Accounts
- Addresses
- Service orders
- Trouble tickets
- Billing inquiries
- Payments
- Marketing
- Notes
- Alerts

### Account Management (AM)
AM covers:
- Premises
- Equipment
- Network
- Service-order inventory
- Bundles
- Assigned services
- Capital credits
- Carriers

### AI Assistant — Mimir
Mimir provides:
- Conversational chat
- Agent mode
- AI-generated charts
- AI-generated insights
- AI-assisted report building
- Summaries of notes and tickets

### Reporting & Analytics
The platform includes:
- Puppeteer-based report engine
- Batch report processing
- Analytics dashboard and widgets
- Saved charts and insights

## Current Scale Mentioned in Source
- 367+ API endpoints
- 69+ CM maintenance screens
- CM + AM databases
- Integrated AI services

## Business Outcome
The modernization is intended to provide:
- A modern web experience instead of desktop software
- Faster service through AI assistance
- One unified CM + AM platform
- Cloud-ready, continuously delivered software
